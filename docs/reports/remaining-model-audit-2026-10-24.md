Real-weight evidence is accepted only for a source-backed executed model and the pinned audio fixture, with the complete normalized result compared against its oracle. A completed inference with a wrong transcript is a quality failure. `UNVERIFIED` means the intended flow did not complete and is not a model PASS or an accuracy failure. Rows distinguish artifact variants and package snapshots where relevant. CPU graph parity proves graph equivalence for the tested inputs; it does not prove ASR transcript accuracy.

## Microphone, VAD and streaming

Physical microphone behavior remains **UNVERIFIED**. Controlled Chromium fake-audio captures are harness evidence only and must not be presented as physical-device validation. File transcription does not prove microphone capture, VAD, or native streaming.

For custom Whisper r5, Realtime receipts report exact controlled-audio transcript status for manual capture and TEN-VAD-only / FireRed-VAD-only detection. The Playground record-then-transcribe receipt also reports exact text. Its separate streaming receipt records runtime `UNSUPPORTED`, stream status `UNSUPPORTED_OFFLINE_FALLBACK`, and missing multiple native streaming steps; it is not a streaming PASS.

Earlier Realtime Parakeet TDT v3 controlled fake-audio runs passed for manual capture and speech-detect with TEN-VAD and FireRed VAD. All three produced the exact JFK transcript; worker GPU dispatch telemetry was 1,281 for manual, 5,104 for TEN-VAD, and 6,380 for FireRed VAD. This proves the controlled browser capture path, not a physical microphone.

A distinct cached `MoonshineStreamingTiny` four-graph bundle completed native Playground chunk streaming in WASM: 17 steps and the full JFK transcript matched. This is separate from offline stacked-cache `Moonshine Tiny`. Models whose runtime handle reports `supportsStreaming: false` cannot receive a native-streaming PASS from offline transcription. Showcase and Benchmark expose no microphone/VAD interface in the audited flow.

The later Omnilingual control uses official Meta `omniASR_CTC_300M_v2` preprocessing and weights, and the pinned 11-second English JFK fixture. Parent compared the 176,000-sample JavaScript waveform with the saved native waveform: max absolute difference `4.7684e-7`, mean absolute difference `2.7265e-8`, `allclose(atol=1e-6, rtol=1e-6)=true`. In Windows ONNX Runtime 1.29, official and SDK inputs produce FP32 logits allclose at `1e-3/1e-4` without changed frame argmax; INT8 differs at frame 52. Linux ONNX Runtime 1.30 versus Windows 1.29 also changes INT8 frames 52, 65 and 75 on the exact official waveform. The epsilon fix verifies preprocessing to the stated tolerance, not cross-runtime INT8 parity or ASR quality. Official native and SDK transcripts on this fixture both fail the immutable English gold. See the [Omnilingual evidence report](../../../speech-recognition/docs/reports/omnilingual-padding-diagnosis-2026-10-24.md).

The Canary v2 source metadata has been corrected against the embedded checkpoint and [NVIDIA model card](https://huggingface.co/nvidia/canary-1b-v2): 16,384 output classes, 32 encoder layers, 8 decoder layers and 25 supported languages. Its descriptor no longer copies the 180M documentation or timestamp claims. The pinned checkpoint, native CPU reference, own ONNX export and actual v10 browser matrix are recorded in the [Canary export report](../../../speech-recognition/docs/reports/canary-v2-export-2026-10-24.md). CPU verification gates shapes, lengths, exact masks, decoder IDs and text; encoder numeric differences are measured but not gated without a defined tolerance. The verifier skipped frontend parity by using native frozen features. The four-app browser results use the JS frontend. GPU dispatch proves GPU work, not full-graph GPU coverage. Benchmark component assignments are not individually exposed.

Nemotron v8 Realtime file/manual/TEN-VAD/FireRed-VAD all executed without console/page errors, but all failed the exact transcript oracle. Playground native streaming executed 17 steps with 26,933 stream GPU dispatches and the same `at` error; this is native execution with failed quality. Playground controlled record-then-transcribe at 21 seconds matched exactly (52,272 inference GPU dispatches). Parent verification independently rechecked all seven receipts; physical microphone remains unverified. The corrected frontend floor-valid frame count did not remove the word error.

The fresh native Nemotron trace subsequently isolated the cache-aware window schedule and unconditional initial graph drop. The v11 optional bundle contract and surgical conditional-drop graph fix that interface. Parent verification rechecked nine completed receipts: all four file flows, three Realtime controlled captures, Playground recording, and 18-step native streaming. All match the unchanged whole-fixture oracle, with nonzero inference GPU work and no verifier/page/console errors. The initial Benchmark attempt failed in harness configuration because it requested absent component controls; it remains preserved. `benchmark-round2/` uses the available WebGPU Hybrid control and passes. This is aggregate backend acceptance; no separate Benchmark component backend claim is made. Native cache-time drift on two steps still fails the unchanged numeric tolerance.
